# Aktualizace AI Studio GHRAB 0.19.0

Toto vydání začleňuje Lesson Hub 1.2.0 jako osmou chráněnou aplikaci.

## Pořadí nasazení

1. Nejprve nasaďte Lesson Hub 1.2.0 a ověřte `/lesson-hub/studio-manifest.json` a `/lesson-hub/manual/`.
2. Potom nahrajte AI Studio GHRAB 0.19.0.
3. Po zeleném workflow ověřte katalog aplikací, kartu Lesson Hubu, centrum manuálů a oprávnění `LHB-01`.
4. Pro pilot používejte anonymizovaná data; server Lesson Hubu zůstává volitelný a ve výchozím stavu vypnutý.
