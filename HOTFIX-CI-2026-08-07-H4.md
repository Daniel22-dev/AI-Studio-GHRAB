# HOTFIX4 — GitHub QA static server

Poslední červený `qa-build` nebyl způsoben aplikací, ale lokálním QA HTTP serverem.

Oprava:

- QA manifest explicitně deklaruje deployment base path `/AI-Studio-GHRAB/`;
- `startStaticServer()` tuto cestu při lokálním QA mapuje na kořen `dist/`;
- visual a critical gate předávají deployment base path statickému serveru;
- absolutní produkční URL jako `/AI-Studio-GHRAB/config/support.json` a `/AI-Studio-GHRAB/config/apps.generated.json` proto v QA již nekončí 404.

Produkční kód aplikace ani datové formáty se tímto hotfixem nemění.
