# AI Studio GHRAB 0.20.14 – CI hotfix 3

Oprava poslední historické GHRAB QA release brány po úspěšném P5 R2 nasazovacím auditu.

- sjednocen aktuální prefix PWA cache `ghrab-ai-studio-v`;
- opraven offline fallback Centra manuálů v service workeru (`manualy/index.html`);
- statická kontrola importů ignoruje JavaScript generovaný uvnitř template literalů;
- kontrola README akceptuje Markdown zvýraznění verze;
- potvrzený fallback registr zůstává potvrzený i při úplné dočasné nedostupnosti živých manifestů, pokud se před spuštěním shodoval s potvrzeným snapshotem;
- visual/critical QA načítá stránky z reálného lokálního HTTP originu místo `about:blank`, takže test nevyrábí falešné CORS chyby;
- statická kontrola izolace cache odpovídá současné namespacované implementaci.

Funkce aplikace, uživatelská data ani verze 0.20.14 se nemění.
