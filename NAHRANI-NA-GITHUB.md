# Nahrání AI Studio GHRAB 0.21.54

> Aktuální verze: **0.21.54** · etapa P5

> 0.21.54 přidává server-ready přehled skutečné spotřeby OpenAI API a automatické finanční údaje do měsíčního reportu. API klíče zůstávají výhradně na školním serveru; GitHub Pages režim žádná finanční data neodhaduje ani API-usage endpoint nevolá.

Verze 0.21.54 navazuje na stávající P5/GARP bezpečnostní baseline. Přidává dvoustránkový reporting z 0.21.51 a připravenou serverovou živou přítomnost; v GitHub Pages profilu je presence vypnutá. Podepisovací klíče, existující revokace a vydaná oprávnění se tímto releasem nemění.
