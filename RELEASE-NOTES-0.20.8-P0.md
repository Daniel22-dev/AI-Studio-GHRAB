# ai-studio-ghrab 0.20.8 — etapa P0

Datum vydání: 4. srpna 2026

Platformní etapa P0: reportér je oddělen od kritické cesty Access Guardu, portál i zamykací obrazovka mají best-effort hlášení, rozšířeno bezpečné čištění sdílených cache a zaveden deployment kontrakt pro GitHub Pages a budoucí školní server.

## Rozsah

- kritické opravy z konsolidovaného auditu;
- zachování stávajících uživatelských dat a výchozího GitHub Pages provozu;
- automatizované buildy a P0 konformní kontroly;
- u aplikací mimo KS příprava na konfigurovatelné nasazení na školní server.
