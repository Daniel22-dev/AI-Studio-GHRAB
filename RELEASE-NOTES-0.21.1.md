# AI Studio GHRAB 0.21.1

Release připravuje záložku **Materiály** na budoucí školní server, aniž by v dnešním GitHub Pages režimu předstíral funkční sdílení. Po serveru je plánován katalog předmětových komisí s verzemi, vlastními kopiemi a stavy **Ověřeno ve výuce** / **Doporučeno komisí**. Klientská repository vrstva a API kontrakt jsou připravené, ale aktivují se pouze při skutečně připojeném school-server profilu.

Bezpečnostní **Rychlá kontrola dat** je nově schovaná pod volbou „Nejsem si jistý → rychle posoudit“ a je výslovně označena jako volitelná místní pomůcka.
