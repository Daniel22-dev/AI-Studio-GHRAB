# AI Studio GHRAB 0.21.28 — stav testování aplikací

- Správcovské karty aplikací obsahují tři odlišné stavy: `○` netestováno, `◐` lehce otestováno a `✓` otestováno.
- Stav se ukládá místně podle ID aplikace a automaticky se vztahuje i na budoucí aplikace.
- Učitelé a Pohled kolegy zůstávají bez této interní QA pomůcky.
- Hlavnímu správci se po výběru role už nevynucuje 14denní expirace; vydavatel nabízí maximální bezpečnou platnost 400 dní.
- Text o platnosti správce a kontrole zneplatněných přístupů byl zpřesněn bez oslabení přístupové ochrany.
