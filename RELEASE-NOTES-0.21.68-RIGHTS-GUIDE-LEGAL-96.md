# AI Studio 0.21.68 — návod k režimu práv A/B/C

Datum: 2026-09-14

## Změny
- U karty nové aplikace / významného vývoje je přímo u volby práv nový rozbalovací návod „Jak zvolit A / B / C?“.
- Varianta A je vysvětlena jako standardní návrh pro rozvoj ekosystému a nové autorovy aplikace; stále vyžaduje výslovnou volbu.
- Varianta B je vymezena pro samostatné školní projekty nebo právně a technicky oddělitelné moduly.
- Varianta C je určena pro granty, externí partnery, více škol, open-source nebo jiný individuální režim.
- Text přednastavených práv je sladěn s právním balíkem 9.6.

Běžné opravy a běžné releasy tím nejsou administrativně zatíženy; kartu vyžaduje pouze významný vývoj nebo nová aplikace.
