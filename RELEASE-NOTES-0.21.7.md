# AI Studio GHRAB 0.21.7

Provozní a UX aktualizace po ručním auditu portálu.

- samostatná, ale plně modrá patička,
- desetibodový bezpečnostní semafor s pravidlem „nejvyšší riziko vítězí“,
- tříúrovňová Kontrola zdrojů: nasazení / GitHub zdroj / snapshot,
- offline QA už nepřepisuje skutečný stav synchronizace,
- přesnější nápověda pro vlastní místní data v souhrnném reportu,
- least-privilege povýšení existujícího trained teacher na Zástupce správce,
- jednotné pilotní popisky karet,
- opravený fullscreen orbit Prezentace,
- opravené přehrávání showcase MP4 přes Range/206 a explicitní play tlačítko.

Materiály zůstávají v serverless režimu lokální; integrace „Uložit do AI Studia“ do ostatních aplikací je další samostatná etapa.
