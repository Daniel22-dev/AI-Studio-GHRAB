1. POZOROVANY PROBLEM
Changelog verze 0.21.49 R3 uvadel, ze hvezdicka osobniho Top 4 a presun Top 4 jsou dostupne i v Pohledu kolegy. V realnem prohlizeci se ale v Pohledu kolegy hvezdicky nezobrazovaly.

2. SKUTECNA PRICINA
Zdrojovy kod R3 byl opraven spravne, ale R3 znovu pouzil stejne cislo verze 0.21.49 jako predchozi R2.

R2 obsahoval admin-only podminky:
- presun Top 4 pouze pri isAdmin() && !isColleaguePreview()
- hvezdicka Top 4 pouze pri isAdmin() && !isColleaguePreview()

R3 tyto podminky ze zdrojoveho app.js odstranil, ale protoze zustala verze 0.21.49:
- service worker dale pouzival cache namespace ghrab-ai-studio-v0.21.49,
- runtime asset byl stale verzovan jako app.js?v=0.21.49,
- prohlizec tedy mohl dale obsluhovat starsi R2 app.js z cache.

To vysvetluje rozpor: dokumentace/changelog byl novy, ale runtime v prohlizeci se mohl chovat jako stary R2.

4. PWA / CACHE OPRAVA

- APP_VERSION = 0.21.50
- CACHE = ghrab-ai-studio-v0.21.50

Tim se stary cache klic 0.21.49 prestava pouzivat pro novy runtime. I kdyby jeste kratce bezela stara 0.21.49 service-worker instance, jeji logika pro asset s jinou ?v= hodnotou pouzije sit misto stare cache.
