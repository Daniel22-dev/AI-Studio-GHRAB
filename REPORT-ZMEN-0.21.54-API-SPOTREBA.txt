GET /api/v1/admin/api-usage a potom aktivovat serverovy profil dle kontraktu:
- authMode = server-session
- features.schoolServerConnected = true
- features.apiUsageReady = true
- features.apiUsage = true
- endpoints.apiUsage = admin/api-usage
Administratorsky OpenAI klic zustava pouze jako serverove tajemstvi.
